# Toggle Interact (Fabric, Minecraft 26.3)

Две независимые клавиши (меняются в Настройки → Управление → Toggle Interact):
- **R** — блоки ставятся на сундуки, печки, верстаки без шифта (вкл/выкл).
- **G** — полёт в творческом режиме без скольжения (вкл/выкл).

Состояние запоминается в config/toggleinteract.txt.

## Как получить jar через GitHub
1. Загрузи все файлы в новый репозиторий на GitHub.
2. Вкладка **Actions** → сборка «Build mod» (или Run workflow).
3. Скачай артефакт **toggleinteract-jar**, возьми jar без `-sources`, положи в mods (нужен Fabric API).
